# climb2claude

公开笔记：怎样把 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 装到自己的环境里，并把它用成日常工具。

仓库说明：hard to climb to claude。

## 记录范围

- 安装和运行环境
- 登录与网络
- 日常用法
- 已经踩过、并且能复现的问题

笔记放在 [`docs/`](docs/README.md)。每篇只写验证过的步骤、预期结果和回退方法。

## 当前状态

第一步是体检，见 [docs/01-check-network.md](docs/01-check-network.md)。落地换成境外小鸡上的通道，分享串落成粮单后再喂给小猫。第二步是养号，见 [docs/02-warmup.md](docs/02-warmup.md)：同一套环境登进去，没事聊几句。2026-10-20 的体检还没有用这只新鸡复测。
