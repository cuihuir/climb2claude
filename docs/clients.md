# 客户端

日期：2026-10-20

粮单喂给下面两个。内核都是 mihomo，都能开系统开关和虚拟网卡。本机核对过的是小猫。

| 叫法 | 仓库 | 安装包 |
| --- | --- | --- |
| 小猫 | [clash-verge-rev/clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev) | [最新发布](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest)，站点 [clashverge.dev](https://www.clashverge.dev) |
| FlClash | [chen08209/FlClash](https://github.com/chen08209/FlClash) | [最新发布](https://github.com/chen08209/FlClash/releases/latest)，站点 [chen08209.github.io/FlClash](https://chen08209.github.io/FlClash) |

小猫覆盖 Windows、macOS、Linux。本机是它。虚拟网卡打开后，WebRTC 的 UDP 已经核对通过。

FlClash 覆盖 Android、Windows、macOS、Linux。手机用它。桌面和手机都能从本地粮单或订阅导入。Fedora 上若用 AppImage 或 rpm，托盘图标需要 `libayatana-appindicator-gtk3`。

两个都从各自仓库的 Releases 下包，不在这里写死版本号。
