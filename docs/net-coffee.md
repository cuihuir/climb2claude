# 体检站

日期：2026-10-20

[ip.net.coffee](https://ip.net.coffee/)

在浏览器里打开。命令行访问同一个网址，看不到 DNS 和 WebRTC。页上的地址不要抄进仓库。

上车前先看 [Claude 体检](https://ip.net.coffee/claude/)。某一项要单独复查时，用下面这些页。

| 页 | 看什么 |
| --- | --- |
| [Claude 体检](https://ip.net.coffee/claude/) | 落地、信任分、DNS、WebRTC、时区、可用性 |
| [IP 评分](https://ip.net.coffee/ip/) | 落地纯不纯 |
| [DNS 泄露](https://ip.net.coffee/dns/) | DNS 是不是还从家门出去 |
| [WebRTC](https://ip.net.coffee/webrtc/) | UDP 出口 |
| [Cloudflare](https://ip.net.coffee/cloudflare/) | Cloudflare 那张出口 |
| [网络连通](https://ip.net.coffee/link/) | 站点通不通 |
| [全球 Ping](https://ip.net.coffee/ping/) | 到各地的延迟 |
| [GPT 检测](https://ip.net.coffee/gpt/) | 另一家的同类体检，用来对照 |
| [服务状态](https://ip.net.coffee/status/) | 服务本身是否在线 |

和这次体检有关的说明页：

- [为什么别用 IPv6](https://ip.net.coffee/claude/ipv6.html)
- [时区和设备信息](https://ip.net.coffee/claude/timezone.html)
- [域名分流](https://ip.net.coffee/claude/site.html)
